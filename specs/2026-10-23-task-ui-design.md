# Spec: TASK-UI — перенос дизайна в приложение
**Date:** 2026-10-23 · **Size:** M · **Research:** `thoughts/research/2026-10-23-task-ui-design.md`

## Goal
Применить `design/tokens.css` и `design/DESIGN.md` к существующим экранам без изменения структуры и логики; две палитры с переключателем в «Питомец → Оформление».

## In Scope
1. Токены: `design/tokens.css` подключается как есть; все цвета в стилях и коде только через `var(--…)`.
2. Палитры: `data-theme` на `<html>`; значения `tishina` (по умолчанию) и `teplo`; выбор в `localStorage['lapa.theme']`; без мигания при загрузке.
3. «Питомец → Оформление»: сегмент «Тишина / Тепло» (остальное на экране — по-прежнему «скоро»).
4. Шрифты: Inter (latin, cyrillic) и Noto Sans Thai (thai), самохостинг; Manrope и Onest удаляются.
5. Типографика, отступы, радиусы, компоненты по DESIGN.md §3–6 для экранов: каталог (список и фильтры), карточка заведения (рейтинги, кнопки, часы, отзывы, окно «Скоро»), карта (метки, кластеры, шторка-превью, «Рядом со мной»), «Рядом», нижняя панель, шапка, баннер тестового режима, состояния загрузка/пусто/ошибка.
6. Иконки во вкладках и шеврон в строке — линейные SVG одной толщины 1,8.

## Out of Scope
Тёмная тема; две панели на планшете и компьютере (DESIGN.md §8) — отдельной задачей; новые экраны и функции; изменение данных, маршрутов, текстов интерфейса (кроме подписей для «Оформления»); цвета подложки карты (настройка в Google Cloud).

## Acceptance Criteria (из задачи)
- [ ] Все пары текста ≥ 4,5:1 в обеих палитрах — тест на контраст по `design/tokens.css`.
- [ ] Нигде нет цветов вне токенов — тест сканирует `src/**/*.{css,ts,tsx}`.
- [ ] Тап-зоны ≥ 44 px — проверка размеров всех кнопок и ссылок в Playwright на 390×844 (обе палитры), вывод в отчёте.
- [ ] Шрифты Inter и Noto Sans Thai самохостингом, подмножества latin, cyrillic, thai; в сборке нет обращений к fonts.googleapis.com / fonts.gstatic.com (`check:bundle`).
- [ ] Скриншоты 390×844 в обеих палитрах: каталог, фильтры, карточка, карта, «Рядом», «Питомец → Оформление».
- [ ] Все прежние тесты зелёные; lint, typecheck, build, `check:bundle`, `npm audit` без ошибок.
- [ ] Ревью по справочникам Impeccable (critique, audit, polish) без запуска движка; по данным ui-ux-pro-max — шрифтовая пара и правила удобства для мобильных.

Добавлено (уточнения, не ослабляют исходные):
- [ ] (добавлено) Палитра: по умолчанию `tishina`; неизвестное значение в хранилище → `tishina`; недоступный `localStorage` не ломает приложение (тесты).
- [ ] (добавлено) Метки и кластеры карты берут цвета из токенов и меняются при смене палитры (тест).
- [ ] (добавлено) Тайский текст (названия заведений, адреса, отзывы на тайском) с межстрочным ≥ 1,4.

## Constraints
`CLAUDE.md` (источник правды по дизайну — `design/`, значения токенов не менять без Макса); движок Impeccable не запускать; mobile-first 390×844, проверка на 320/375/414/768; строки интерфейса только в i18n.
