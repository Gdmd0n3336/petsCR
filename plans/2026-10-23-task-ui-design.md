## Фазы (TDD)
### Фаза 1. Токены, палитры, шрифты
- Тесты: контраст 17 пар × 2 палитры по `design/tokens.css` (≥ 4,5); `theme.ts` — по умолчанию `tishina`, сохранение и чтение `lapa.theme`, неизвестное значение → `tishina`, хранилище бросает — не падает, `data-theme` выставляется; inline-скрипт в `index.html` разбирает только два значения; «нет цветов вне токенов» (пока красный — станет зелёным в фазе 2).
- Код: `src/lib/theme.ts`, `useTheme`, inline-скрипт; импорт токенов; `fonts.css` на Inter + Noto Sans Thai; удалить `@fontsource-variable/manrope` и `onest`, добавить `@fontsource-variable/inter@5.3.0` и `@fontsource-variable/noto-sans-thai@5.3.0` (точные версии); `check:bundle`: нет `fonts.googleapis.com`/`fonts.gstatic.com`, есть woff2 Inter latin/cyrillic и Noto Sans Thai thai.
### Фаза 2. Стили по DESIGN.md
- Переписать `styles.css` на токены: типографика (шкала §3), отступы 4–24, поля 20, радиусы 16/13/22/20, сгруппированные списки, чипы, сегменты, кнопки ≥ 50, нижняя панель с иконками и размытием, фиксированная кнопка в карточке, шторка на карте, баннер, состояния; `:lang(th)` и названия заведений — межстрочный ≥ 1,4.
- Разметка без изменения логики: `Icon` (вкладки, шеврон), обёртка шторки с ручкой, крупный заголовок экрана; прежние тесты должны остаться зелёными без правки ожиданий (кроме мест, где проверялась старая разметка — правки показать в отчёте).
- Метки и кластеры карты из токенов + пересоздание при смене палитры (тест на подменённой карте).
### Фаза 3. «Питомец → Оформление»
- Тесты: сегмент «Тишина / Тепло», выбор меняет `data-theme` и сохраняется, после перезапуска восстанавливается.
- Код: секция в `PetScreen` (остальное — «скоро»), строки в `ru.ts`/`en.ts`.
### Фаза 4. Проверка и ревью
- Скриншоты 390×844 в обеих палитрах: каталог, фильтры, карточка, карта (живые данные), «Рядом», «Питомец → Оформление»; проверка 320/375/414/768; Playwright-замер тап-зон.
- Ревью по справочникам Impeccable `reference/critique.md`, `audit.md`, `polish.md` и `craft-floor.md` (без движка); ui-ux-pro-max: шрифтовая пара и правила для мобильных (`--domain typography`, `--domain ux`); исправить найденное; отчёт по разделу 10 ТЗ. PR — по слову Макса.

## Вопросы к Максу
1. **Подложка карты (`--map-*`).** С Map ID цвета карты задаются только стилем в Google Cloud. Варианты: (а) пока оставить стандартную карту Google, а токены применить к меткам, кластерам, шторке и точке «Вы здесь» (предлагаю); (б) вы создаёте в Google Cloud стиль карты по `--map-*` и привязываете к текущему Map ID (одна подложка на обе палитры) или заводите второй Map ID для «Тепло».
2. **Иконки.** Свои 8 SVG (предлагаю) или `lucide-react` (точная версия старше двух недель, например 1.5x)?
3. **Крупный заголовок.** Название вкладки как заголовок экрана («Каталог», «Рядом», …), а «Lapa» только в заголовке страницы браузера — подходит? Или оставить «Lapa» над названием экрана?
4. **Фиксированная кнопка «Записаться или спросить»** над нижней панелью в карточке — подтверждаете (DESIGN.md §4)?
