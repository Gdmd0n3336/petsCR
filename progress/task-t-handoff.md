## Как продолжить
1. Распаковать архив в корень репозитория: `tar xzf task-t-partial-2026-10-20.tar.gz` (появится `data/`).
2. В сессии Claude Code запустить `scripts/translate/workflow.js` инструментом Workflow, `args.batches` = список из `data/translations_remaining.json` (+ при желании все 50 пакетов для проверки 5 — переводчик пропустит только b-001; для уже переведённых пакетов лучше отдельный сценарий «только verify → fix → reverify»).
   - В среде с 4 ядрами Workflow запускает 2 агента одновременно: ~1,5 мин на пакет перевода, столько же на проверку → ~2 ч на остаток. На машине с большим числом ядер — быстрее.
3. Собрать: `node scripts/translate/assemble.mjs` (полный режим, проверки 1–5) или `node scripts/translate/export-partial.mjs` (только готовые пакеты).
4. Названия: агенты из того же сценария (этап Venues), проверка `node scripts/translate/venues.mjs check 1|2`, сборка `node scripts/translate/venues.mjs assemble`.
